Berkeley Open Infrastructure for Network Computing — platform for volunteer computing.

## Projects

Setting up a BOINC server for the **urban@home** project to run distributed urban simulations.

## Notes

- First encountered BOINC via SETI@home in 1999/2000 on an iMac G3
- Server setup involves many phases: VM, MySQL, Apache, scheduling
- Work unit generation and result validation are the key pieces to get right
