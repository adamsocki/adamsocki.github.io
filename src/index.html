Transportation planner by day. Developer by night.

This site is a project archive: a place to collect technical experiments, prototypes, unfinished systems, and things learned along the way. The point is not to make every project look like a startup. The point is to give the work somewhere to land.

Start with the project archive. It includes active work, paused experiments, and archived projects with notes about what worked, what did not, and what might be reused later.

Current focus

  • Stock Strategy Lab: a local TypeScript/Bun app for market-data experiments, backtesting, and strategy research.
  • Comma.ai Controls Challenge: a controller-optimization project using genetic algorithms and simulation.
  • Project Archive: turning scattered code, notes, and experiments into visible artifacts.
