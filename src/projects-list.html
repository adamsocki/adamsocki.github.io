Project Archive

This is a shelf for projects, prototypes, and technical experiments. Some are active, some are paused, and some are archived because the lesson was more useful than the finished product.

Each project page should answer a few simple questions: what it is, why it exists, what works, what was learned, and what would come next.

Status key: active = currently moving, paused = worth preserving but not current, planning = concept/prototype, archived = tombstone or lesson learned.
