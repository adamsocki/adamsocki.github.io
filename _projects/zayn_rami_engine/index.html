zayn|rami - Vulcan Game Engine

Overview

zayn|rami is a game engine built in C++ using the Vulkan API. It is designed to be a lightweight, high-performance engine for creating 3D games and applications. The engine is currently in development and is not yet ready for production use.

Features

  • Vulkan Rendering: Utilizes the Vulkan API for high-performance graphics rendering.
  • Entity-Component-System (ECS): Implements an ECS architecture for efficient game object management.
  • Physics Engine: Includes a physics engine for realistic simulations.
  • Asset Management: Supports loading and managing various types of assets such as models, textures, and shaders.
  • Input Handling: Provides robust input handling for keyboard, mouse, and gamepad.
  • Scripting: Supports scripting in C++ for game logic and behavior.

Getting Started

To get started with zayn|rami, follow these steps:

  1. Clone the Repository:

    git clone https://github.com/adamsocki/zayn-rami.git

  2. Build the Engine:

    cd zayn-rami
